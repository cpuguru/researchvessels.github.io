Search equipment across the fleet

Find ships that carry a given instrument or system. This prototype searches the operator-maintained equipment list, which so far covers only a handful of vessels.

Prototype. Results come from the compiled equipment records only (currently four ships). A query such as “EM124” should find Atlantis. Wire examples such as “0.680 fiber-optic” will match when that text is in a record; it is not in the current seed set. Personal contact details are never shown.

Operators can add or correct equipment on the For operators page. Every change is reviewed before it is published.
